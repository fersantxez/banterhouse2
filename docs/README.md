# Guía de lectura

Banterhouse 2 — **¡Devuelto!** es un juego arcade para Amstrad CPC 6128. Esta documentación tiene tres puertas de entrada: jugar, conocer el mundo y aprender a construirlo.

## Quiero jugar

Empieza por [la guía del jugador](game/PLAYING.md): disco, arranque, controles y qué hacer cuando una máquina se empeña en mandarte trabajo. No necesitas saber programar.

[La historia](game/STORY.md) presenta a Pitu, la agencia y los cuatro capítulos. Distingue la aventura imaginada de lo que ya contiene el prototipo.

## Quiero entender cómo se hace

1. [Primera compilación](development/GETTING_STARTED.md): desde una copia del código hasta un DSK.
2. [Cómo funciona el juego](development/ARCHITECTURE.md): entrada, simulación, dibujo y cargas de disco, siguiendo una partida.
3. [Gráficos y música](development/ASSETS_AND_AUDIO.md): cómo llegan un dibujo y una melodía al CPC.
4. [Cómo se prueba](development/TESTING.md): qué demuestra cada prueba y qué queda fuera.
5. [Mapa del repositorio](development/REPOSITORY.md): dónde cambiar cada cosa.
