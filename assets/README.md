# Recursos del juego

| Carpeta | Contenido |
|---|---|
| [loading](loading/README.md) | La portada utilizada por el arranque y su conversión CPC |
| `levels/` | 24 arenas, geometría y vistas de colisión generadas |
| `source/canonical/` | Las 35 entradas gráficas congeladas con hashes |
| [cpc-studies](cpc-studies/README.md) | Estudios nativos que explican el origen y los límites del arte |

Las exploraciones artísticas descartadas y las referencias privadas no son necesarias para construir el juego y están fuera del repositorio. La música actual se genera desde `tools/build_pop_ay.py`.

[Cómo se producen los recursos](../docs/development/ASSETS_AND_AUDIO.md).
